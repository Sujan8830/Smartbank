SmartBank

Java REST API with an Angular front end

Open an account, then move some money.

This is a working demo. Every deposit and withdrawal is saved by a Java and JDBC backend, and the passbook is read back from the database.

The free server can take up to 30 seconds to wake up.

The demo database resets when the server restarts, so older account numbers may stop working.
